# NFX — NITF File eXchange

A MATLAB toolbox for constructing and writing NITF files through a compact object-oriented API in the `nfx` namespace.

Early development: implementation is not yet available. The first candidate targets NITF 2.1 with one uncompressed, blocked image segment and an RPC00B TRE, accompanied by a full unit test suite.

Targets MATLAB R2023b and newer; development and testing use R2026a. No GDAL or NITRO dependency is planned. MATLAB Coder compatibility is a design objective and is not yet verified.

Usage documentation will follow the first implementation.
